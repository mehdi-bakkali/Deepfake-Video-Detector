# Contributing

Contributions that improve clarity, reproducibility, accessibility, or evaluation are welcome.

Before opening a pull request:

1. Describe the change and the problem it addresses.
2. Keep datasets, uploaded videos, checkpoints, and credentials out of commits.
3. Preserve the distinction between a model score and a verified authenticity claim.
4. For performance claims, include the dataset split, class balance, metrics, threshold selection method, and relevant limitations.

The DFDC data and pretrained weights have terms that are separate from this source code. Check those terms before sharing data or model artifacts.
